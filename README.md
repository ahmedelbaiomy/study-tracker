# 📚 Zaker (ذاكر) – Study Tracker App

Zaker is a modern study tracker web application designed to help students organize their learning, track progress, and stay consistent with their study goals.

🌐 Live Demo: https://zaker-app.netlify.app

---

## ✨ Features

- 📅 Daily study tracking  
- 🎯 Goal setting for subjects or topics  
- 📊 Progress monitoring  
- 🧠 Simple and distraction-free UI  
- ⚡ Fast and responsive design  
- 📱 Mobile-friendly interface  

---

## 🛠️ Built With

- Angular  
- TypeScript  
- HTML5  
- CSS3  
- Netlify (Deployment)
